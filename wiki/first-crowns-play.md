# 작은 관들의 시절 — 용사물 플레이 시작 규칙

> **룰북 변주 초안 · 진행 가능.** [항로 시대 탐사대 룰북](./rulebook.md)을 그대로 판정의 뼈대로 쓰되, 한 사람의 용사 후보와 자율적인 동료들, 작은 왕국들과 문턱골의 전쟁을 무대로 삼는다. 이 문서는 기존 항로 시대 탐사대와 별개 세션이며 소엘·물새호의 시트와 세계 상태를 고치지 않는다.

## 누가 무엇을 움직이는가

플레이어는 **한 인물의 행동·말·내심**을 결정한다. 나머지 동료, 왕, 병사, 숲, 문, 마왕 에른은 진행자가 각자의 지식과 동기로 움직인다. 소엘 플레이처럼 동료는 제안·거절·충돌·실수·선행을 하고 주인공과 함께 성장한다. 파티의 인원은 정해져 있지 않다. 동행한 사람이 떠날 수 있고 새 사람이 합류할 수 있다.

**진행자의 한 차례:** 두세 문단의 장면 → 위험·시간·현재 정보를 명료하게 제시 → 필요한 경우만 판정 → 실제 결과와 달라진 관계·시계 반영 → 상태 줄 → 플레이어에게 행동을 넘긴다. 세계와 숨은 정보는 [진행자 기록](./first-crowns-fronts.md)을 따른다. 플레이어 인물이 알지 못하는 진상을 처음부터 설명하지 않는다.

## 판정과 비용 — 원본에서 지키는 것

**2d6 + 몸·감각·머리·마음.** 네 능력에 +2, +1, 0, -1을 하나씩 배분한다. 10 이상 성공, 7~9 성공하되 대가, 6 이하 실패와 경험 1. 유리면 3d6 중 높은 둘, 불리면 낮은 둘. 동료의 실제 조력이 성립하면 +1을 받되 위험도 함께 진다. 위험하고 불확실할 때만 굴린다. 굴림에는 두 주사위 눈과 보정을 공개한다. 진행자가 굴리면 실제 난수로 굴리고 결과를 바꾸지 않는다.

살핀다(감각), 알아낸다(머리), 사이에 청한다(보통 감각, 사람 상대일 때 마음 가능), 맞선다(몸), 설득한다(마음), 돌본다(머리), 버틴다(몸/마음), 위험을 무릅쓴다(해당 능력)는 룰북의 판정과 결과를 그대로 쓴다. 길을 연다는 항로 개척 특기 대신 이 시대의 **문을 돌본다/길을 찾는다** 행위에 사용한다(해당 장소와의 사이·지식·시간이 실제로 있을 때). 물리적 산길은 걸을 수 있으며 문을 모른다고 모든 이동이 불가능하지 않다. 개척지 우주 항행용 틈 표·배 상태·항로청 표는 적용하지 않는다.

**상처 0~3**, **지침 0~3**, **공동 보급 0~6**. 상처 2면 몸 판정 불리, 3이면 쓰러짐. 지침 3이면 모든 판정 불리. 안전한 숙소에서 하룻밤 쉬면 지침 1 회복, 상처는 치료하거나 충분히 쉬어야 한다. 위험한 야외에서 하루를 보내면 보급 1을 쓴다. 보급 0에서 하루마다 지침 1. 처음은 보급 4/6, 공동 자금 2, 상처·지침 0. 이야기 밖에서 허공의 보급·병사를 만들지 않는다.

**마법은 관계와 값**이다. 보통 사이로 가능한 크기, 결의 유불리, 성공 시 값(몸·사이·장소·약속), 식음과 끊김, 깊음의 판정을 룰북 그대로 따른다. 6 이하의 판정은 실패해도 일이 진행되지만, 불가능한 마법을 뜻밖의 성공으로 바꾸지는 않는다. 마왕의 강한 힘과 플레이어의 시도는 같지 않으며 적의 능력도 미리 정한 조건과 한계를 지킨다.

## 포지션의 특기 — 기존 여섯 직업의 대응

| 자리 | 시작 특기(하나만 선택) | 준비물의 예 |
| --- | --- | --- |
| 선봉 | 맞선다 +1; 습격 때 먼저 위험을 짚는다 | 길든 창, 가죽 옷 |
| 길잡이 | 자신이 실제로 읽을 줄 아는 길·문을 찾는 판정 +1 | 길돌 조각, 짚신 |
| 해독자 | 기록·매듭·옛 흔적을 알아내는 판정 유리 | 기록 끈, 판 |
| 조율자 | 임무마다 한 번 주변의 있는 것들로 쓸 만한 수선 도구를 만든다 | 줄, 접는 바늘 |
| 돌보는이 | 돌본다 +1, 임무마다 한 번 위독한 이를 안정시킨다 | 물막 천, 약초 |
| 교섭자 | 설득한다 +1, 처음 만난 존재와 짧은 뜻을 주고받을 조건을 찾는다 | 선물 줄, 빈 의자 천 |

특기는 힘의 출처를 지정하지 않는다. '선봉'도 기다림과 사이를 맺을 수 있다. 누구든 다른 자리의 실무를 시도할 수 있으며 경험 5를 지우고 다른 자리 특기를 배울 수 있다(능력 +1 최대 +3, 새 사이, 기존 사이 깊음도 선택 가능). **경험은 6 이하가 나올 때마다 +1, 임무에서 새것을 발견하거나 개인 동기를 진전시키면 마감 +1**이다.

## 바로 시작할 수 있는 후보 넷

| 이름 / 자리 | 몸·감각·머리·마음 | 시작 사이 둘 | 왜 길에 나서는가 |
| --- | --- | --- | --- |
| **라헨** / 선봉 | +2, +1, -1, 0 | 휘어진 방패 메움 / 무너지는 사람 앞에 서던 발판 | 동생 무아를 찾는다 |
| **하마** / 해독자 | -1, +1, +2, 0 | 젖은 돌장부 / 새기국 비늘장 | 지워진 출입 기록을 읽어 낸다 |
| **시온** / 길잡이 | 0, +2, +1, -1 | 길의 그늘 / 기울문 서쪽 수선막 | 문을 되살려 길을 여는 사람으로 기억된다 |
| **누이르** / 돌보는이 | -1, +2, +1, 0 | 식히는 천 / 굽이국의 오래된 물동이 | 전쟁이 생겨도 죽일 필요 없는 이를 살린다 |

그 외 [사람들](./first-crowns-people.md)의 어떤 인물도 플레이어로 정하거나 새 인물을 직접 만들 수 있다. 개인의 재능이나 성격은 시트의 두 사이를 구체적으로 정하면서 확정하며, 시작부터 마왕급 힘이나 세계의 숨은 정답을 갖지 않는다. 처음 선택한 인물과 **실제로 동행하는 이**만 판정하고, 나머지는 독립해서 움직인다.

## 세션 시작·선택·저장

기본 시작은 [첫 의뢰 — 서쪽 지킴돌이 비었을 때](./first-crowns-missions.md)의 첫 장면이다. 먼저 플레이어가 맡을 인물을 정하고, 시작할 때는 **공개 장면만** 보여 준다. 사용자가 다른 의뢰를 원하면 공통 출발 상태에서 그 의뢰로 시작하고 아직 일어나지 않은 다른 의뢰의 사건을 확정하지 않는다.

진행 중에는 GitHub 문서를 고치지 않는다. 마감할 때 이번 캠페인 전용 세션 기록과 인물 시트의 저장 블록을 [PLAY.md](../PLAY.md)의 **탐사대 룰북 세션** 원칙에 따라 한 묶음으로 기록한다. 항로 시대 인물 시트나 자유 서사의 story-state를 덮어쓰지 않는다.

**저장 블록 최소 필드:** 시대·지역·경과 날 / 플레이어 이름·포지션·능력치·사이와 깊이 / 상처·지침·경험 / 동료별 현재 위치·정서·목표 / 보급·자금 / 의뢰별 사실과 실제로 획득한 정보 / 각 세력 시계 / 새로 결정한 사건·설정 / 진행자용 비공개 진상과 출처.

## 판정의 공정함

주인공이 충분히 준비해 적장을 꺾을 수 있으면 실제로 꺾는다. 사후에 새로운 무적 능력이나 불가능한 조건을 보태지 않는다. 피해와 죽음은 진짜지만 모험을 어렵게 만들기 위해 매번 비극을 의무화하지 않는다. 인물들은 체면, 애착, 공포와 오해로 무리한 행동을 할 수 있다. **적은 자기 계획을 실행하며 실제로 전진한다.** 전투나 탈출이 벌어지면 실제 거리를 적고, 필요하면 위험 시계를 굴린다.

[원본 룰북](./rulebook.md)에 없는 지역 전용 표는 사전에 기록한다. 임의의 사건은 신탁으로 결정하되, 이미 정한 비밀·능력·동기까지 신탁으로 바꾸지 않는다.
