# 소엘 — 탐사대 기록관 시트

> 물새호 탐사대의 기록관. [탐사대 룰북](./rulebook.md)의 준비된 대원으로 시작했다. 첫 의뢰 [이름을 바꾼 배](./soel-session-01.md)에서 매듭 읽기 책과의 사이를 깊음까지 키웠다.

## 기본

| 항목 | 내용 |
| --- | --- |
| 역할 | 기록관 |
| 배 | 물새호 (작은 건넘선, 승무원 넷, 고리운송에서 빌린 배) |
| 동료 | 리안(길잡이), 도하(정비사), 카이(경계원) — 진행자가 움직임 |
| 왜 왔나 | 돌아온 별의 매듭을 처음 읽는 사람이 되고 싶다 |
| 플레이어 | 사용자 |

## 능력치

| 몸 | 감각 | 머리 | 마음 |
| --- | --- | --- | --- |
| -1 | +1 | +2 | 0 |

상처 0/3 · 지침 0/3 · 경험 0

## 마법과 기술

- **사이: 스승에게 받은 매듭 읽기 책 — 깊음.** 청할 때 유리. 끊어지거나 닳은 매듭에 남은 뜻을 읽고, 매듭의 약속이 아직 살아 있는지, 누구와 이어져 있는지 따라갈 수 있다.
- **사이: 호수문 결 학회 서고 — 보통.**
- **특기:** 유적, 옛 매듭, 낯선 글에 관해 알아낸다 판정이 유리.

## 장비

기록판, 매듭 읽기 책, 짝돌 한 쌍(현장용으로 두 쪽을 다 가지고 다녔다. 한 쪽은 고리 7호의 용골에 묶어 두었고, 다른 쪽은 리나 에스가 가지고 있다), 기록관의 끈.

## 내력과 목표

호수문 결 학회에서 매듭 읽기를 배웠다. 돌아온 별의 매듭을 처음 읽는 사람이 되는 것이 목표다. 첫 의뢰에서 바람고원식 재회 매듭을 읽어 냈고, 바람고원 사람들이 배 이름을 지우지 않고 더해 새긴다는 학회 서고의 기록을 썼다.

| 때 | 무엇 |
| --- | --- |
| 항로력 212년, 첫 의뢰 | 경험 5 → 매듭 읽기 책의 사이를 깊음으로 |

## 저장

```
[저장 — 항로력 212년 ○철 ○물때 · 첫 의뢰 직후]
탐사대: 소엘 / 기록관 / 몸 -1·감각 +1·머리 +2·마음 0 / 매듭 읽기 책(깊음), 호수문 결 학회 서고(보통) / 상처 0·지침 0 / 경험 0
배: 물새호 / 보급 6/6 / 멀쩡 / 자금 4 / 길돌: 기본
임무: 「이름을 바꾼 배」 완료. 그늘역 3번 부두에 정박 중
알게 된 것: 늙은갈매기호(고리 7호)의 용골에 옛 이름과 재회 매듭을 되살리고 새 이름을 더해 새김. 리나 에스가 짝돌로 배와 작별함. 리나가 젊을 때 문그늘에 들어갔다 등이 다 꺼진 채 돌아온 배를 보았다고 함
진행자 메모: 리나의 이야기는 「바람 끝의 손님들」로 이어진다
새로 정한 것: 마테(고리운송 부두 담당자), 오스반(부두 사무소장), 하람(요양소 의무관, 리나의 손녀), 유안(고리 7호 고정 길잡이), 고리운송 길잡이 이레 순환 규정
```
