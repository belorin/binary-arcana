# 소엘 — 탐사대 기록관 시트

> 물새호 탐사대의 기록관. [탐사대 룰북](./rulebook.md)의 준비된 대원으로 시작했다. 첫 의뢰 [이름을 바꾼 배](./soel-session-01.md)에서 매듭 읽기 책과의 사이를 깊음까지 키웠고, 둘째 의뢰 [방금 떠난 야영지](./soel-session-02.md)에서 돌아온 별의 옛 매듭을 처음 읽었다.

## 기본

| 항목 | 내용 |
| --- | --- |
| 역할 | 기록관 |
| 배 | 물새호 (작은 건넘선, 승무원 넷, 고리운송에서 빌린 배) |
| 동료 | 리안(길잡이, 남), 도하(정비사, 여), 카이(경계원, 남) — 진행자가 움직임 |
| 왜 왔나 | 돌아온 별의 매듭을 처음 읽는 사람이 되고 싶다 |
| 플레이어 | 사용자 |

## 외형

20대 중반 여성. 어깨까지 오는 검은 머리를 대충 묶었고, 한쪽 눈에 끼는 작은 확대 렌즈를 목걸이 끈에 걸고 다닌다. 먹물 자국이 남은 손가락. 소매 끝이 닳은 남색 학회 외투에 주머니가 많은 조끼를 입고, 허리에 끈 뭉치와 기록판을 찬다. 낡은 가죽 표지의 매듭 읽기 책을 늘 끼고 다닌다. 표정은 차분하지만 눈은 늘 무언가를 읽고 있다.

## 능력치

| 몸 | 감각 | 머리 | 마음 |
| --- | --- | --- | --- |
| -1 | +1 | +2 | 0 |

상처 0/3 · 지침 0/3 · 경험 1

## 마법과 기술

- **사이: 스승에게 받은 매듭 읽기 책 — 깊음.** 청할 때 유리. 끊어지거나 닳은 매듭에 남은 뜻을 읽고, 매듭의 약속이 아직 살아 있는지, 누구와 이어져 있는지 따라갈 수 있다. 결을 긴 기록처럼 읽어 낸다.
- **사이: 호수문 결 학회 서고 — 보통.**
- **특기:** 유적, 옛 매듭, 낯선 글에 관해 알아낸다 판정이 유리.
- **맺어 가는 중:** 돌아온 별 남쪽 소금 평원. 경계에 짝돌을 매듭으로 묶어 두었다. 아직 사이는 아니다.

## 장비

기록판, 매듭 읽기 책, 기록관의 끈, 소금시계, 기록 소금 샘플 둘(바깥 고리의 빈 소금 · 섞여 버린 천막 자리의 소금), 짝돌 한쪽(다른 쪽은 소금 평원 경계의 말뚝에 묶여 있다).

## 내력과 목표

호수문 결 학회에서 매듭 읽기를 배웠다. 서고지기 오미르 노인과 아는 사이다. 돌아온 별의 매듭을 처음 읽는 사람이 되는 것이 목표이고, 소금 평원 한가운데에서 누리의 옛 매듭 "늦게 옴"을 읽어 그 목표에 다가갔다.

## 성장 기록

| 때 | 무엇 |
| --- | --- |
| 첫 의뢰 「이름을 바꾼 배」 | 경험 5 → 매듭 읽기 책의 사이를 깊음으로 |
| 둘째 의뢰 「방금 떠난 야영지」 | 임무 종료 경험 +1 |

## 저장

```
[저장 — 항로력 212년 ○철 ○물때 · 둘째 의뢰 직후, 그늘역]
탐사대: 소엘 / 기록관 / 몸 -1·감각 +1·머리 +2·마음 0 / 매듭 읽기 책(깊음), 호수문 결 학회 서고(보통) / 상처 0·지침 0 / 경험 1
배: 물새호 / 보급 5/6 / 멀쩡 / 자금 2 / 길돌: 기본
장비: 소금시계 다섯, 묵힘 주머니, 기록 소금 샘플 둘, 짝돌 한쪽(다른 쪽은 소금 평원 경계)
임무: 「방금 떠난 야영지」 완료. 그늘역에서 정비 중
알게 된 것: 소금 평원은 머문 것을 새기고 늦게 읽어 준다. 한가운데에 "늦게 옴" 매듭과 "백로대. 보았음. 묻어 둠." 매듭. 오미르가 백로대였다
진행자 메모: 오미르는 짝돌로 할 이야기가 아니라며 직접 오라고 했다
새로 정한 것: 토르바와 모래쥐호, 기록 평원, 백로대, 오미르, 늦게 옴 매듭, 소금시계, 대원들의 외형
```
