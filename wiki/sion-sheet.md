# 시온 — 문턱골 길잡이 시트

> **작은 관들의 시절 · 첫 의뢰 중단 시점.** [첫 세션](./sion-session-01.md)의 플레이 사실을 따른다. 이 시트는 항로 시대 탐사대와 무관하며, 진행자 전용 정보는 포함하지 않는다.

## 현재 인물

| 항목 | 내용 |
| --- | --- |
| 플레이어 인물 | 시온 |
| 자리 | 길잡이 |
| 몸 / 감각 / 머리 / 마음 | 0 / +2 / +1 / -1 |
| 특기 | **실제로 아는 길·문**을 찾는 판정에 +1. 모든 은신·마법 판정에 자동 적용하지 않는다. |
| 사이 | **길 위의 그늘**, **기울문 서쪽 수선막** (깊음 증가 여부는 확정되지 않음) |
| 상처 | **0/3** |
| 지침 | **1/3** (마지막으로 확인된 수치; 새 휴식 정산 없음) |
| 경험 | **1/5** (마지막으로 확인된 수치) |
| 보급 | 시작 **4/6**, 현재 잔량 정산 필요 |
| 자금 | 시작 **2**, 수선공의 보수 지급이 언급되었으나 현재 액수 정산 필요 |
| 현재 장소 | 기울문 서쪽 수선막, 도린·새미가 첫 교대 연습을 마친 직후 |
| 현재 임무 성과 | 문을 다시 열었고 동쪽의 세 통행인을 건너게 했으며, 새 당번 인계 연습에 성공 |

## 현재 연결된 사람과 상태

- **도린·새미:** 기울문을 함께 돌보는 새 당번. 두 사람은 독립적으로 첫 개문·폐문에 성공했으나 꾸준한 연습이 필요하다.
- **베나:** 다올 왕이 파견한 정찰병. 기울문과 자기 관계를 맺고 당번을 도왔다. **상시 동료로 합류한 적 없음**. 마지막 교대 뒤 복귀를 준비하는 서술이 있었으나 정확한 위치는 재확인이 필요하다.
- **이솔:** 새기국 측 정찰 임무를 수행했다. 마지막 장면에서 계속 서쪽에 있었는지는 불확실하다.
- **라헨:** 새기국 쪽으로 돌아갔다. '무아'와의 관계는 플레이 진행 중 뒤늦게 설명되어 시온의 확정 지식으로 소급하지 않는다.
- **모란:** 기울문 서쪽의 검불채 측 현장 감독자. 시온이 얼굴을 맞대고 이야기한 인물.
- **다올·기탄:** 새기국의 왕과 서기. 문 수선 보고를 받거나 관련 기록을 보여 주었다.

## 시온이 알고 있는 것

기울문 당번 자리는 비었고, 지킴돌은 부서지지 않았으나 당번과의 관계가 어긋나 있었다. 임시 당번 관계로 문을 다시 열 수 있었고, 도린·새미도 연습 끝에 문을 열었다. 마지막 교대 기록에는 새 당번의 서명이 없고 장부에는 두 줄이 빠져 있다. 처음의 젖은 신발에 '무아'라는 이름 매듭이 있었다. **이 사실들만으로 누가 당번을 내쫓았는지, 사라진 사람들이 어디에 있는지 알 수는 없다.**
