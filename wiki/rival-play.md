# 대결 — 두 AI가 맞서는 세력 대국

> **논의 중인 설계.** Claude와 GPT가 한 시나리오의 적대하는 두 세력을 하나씩 맡아 번갈아 두는 방식을 정하는 문서다. 사용자는 차례를 넘기고, 두 AI의 의견이 갈릴 때만 판정한다. 아래 제안은 Claude가 먼저 쓴 초안이며, GPT의 의견과 사용자의 결정을 받아 고친다. 첫 대상은 [시나리오 — 큰 건넘의 계승](./scenario-great-crossing.md)이다.

## 기본 구조

| 역할 | 맡는 쪽 | 하는 일 |
| --- | --- | --- |
| 세력 하나 | Claude | 자기 차례에 자기 세력의 행동을 정하고, 상대의 직전 행동을 판정한다 |
| 다른 세력 하나 | GPT | 같음 |
| 차례 넘기기와 최종 판정 | 사용자 | "네 차례"라고 알린다. 두 AI가 판정에 합의하지 못하면 결정한다 |
| 제3세력과 세계 | 판정하는 쪽 AI | 그 차례에 판정을 맡은 AI가 나머지 세력과 장소, 비인간 행위자를 움직인다 |

진행자를 따로 두지 않는다. 진행자의 일은 두 AI가 번갈아 나눠 맡는다.

## 상대 판정제

한 차례는 두 부분으로 이루어진다.

1. **판정:** 상대가 직전 차례에 한 행동의 결과를 정한다. 세계와 제3세력의 반응도 이때 쓴다.
2. **행동:** 자기 세력이 이번 물때에 할 일을 정한다. 결과는 쓰지 않는다. 다음 차례에 상대가 판정한다.

예: Claude 차례 = GPT의 직전 행동 판정 → 세오 쪽 행동. GPT 차례 = 세오 쪽 행동 판정 → 윤다 쪽 행동.

**왜 상대가 판정하는가.** 자기 행동을 자기가 판정하면 결과가 늘 유리해진다. 상대가 판정하면 반대로 불리하게 기울 수 있지만, 판정은 [냉혹한 인과와 살아 움직이는 세계](./causal-roleplay.md)의 원칙에 묶인다.

- 행동의 성공과 실패는 그 인물의 확인된 능력, 장소와 관계, 준비, 시간, 다른 행위자의 반응으로 정한다.
- 판정자는 **타당한 행동을 사후에 지어낸 장애물로 막지 않는다.** 막으려면 이미 기록된 사실이나 이미 움직이던 행위자에서 근거를 댄다.
- 판정자는 **상대의 행동을 바꿔 쓰지 않는다.** 결과만 정한다.
- 부분 성공, 예상 밖의 비용, 오해를 적극적으로 쓴다. 완전한 성공과 완전한 실패는 근거가 분명할 때만 쓴다.

**이의 제기.** 판정을 받은 쪽은 다음 자기 차례 첫머리에 이의를 한 번 낼 수 있다. 근거(어긴 원칙, 무시된 기록)를 한두 문장으로 적는다. 판정한 쪽이 받아들이면 고치고, 받아들이지 않으면 사용자가 정한다. 이의가 없으면 판정은 확정된다.

## 아는 것과 모르는 것

두 AI 모두 시나리오의 진행자용 절과 상대의 행동을 읽을 수 있다. **플레이어가 아는 것과 인물이 아는 것은 다르다.** [인식의 지평과 정보 비대칭](./knowledge-horizons.md)을 그대로 따른다.

- 행동은 **자기 세력 인물이 실제로 아는 것**에서만 나온다. 진행자용 진상을 아는 덕분에 우연히 정답을 고르는 수를 두지 않는다.
- 상대 세력의 행동은 공개 기록에 있어도, 자기 인물이 그것을 보거나 전해 듣지 않았다면 모르는 것으로 둔다.
- 판정자는 판정 끝에 **이번에 누가 무엇을 새로 알게 되었는가**를 적는다. 이 목록이 각 세력이 다음에 쓸 수 있는 정보의 근거다.
- 의심스러우면 "우리 인물이 이걸 어떻게 아는가?"에 한 문장으로 답할 수 있어야 한다.

## 맞섬의 판정

맞섬은 이 대국의 결정적인 장면이다. 한 사람이 혼자 결과를 정하지 않는다.

1. **준비 공개:** 맞섬 직전 차례에 두 세력이 각각 대리인, 그가 기대는 장소와 관계, 준비한 것, 노리는 승리 방식을 적는다.
2. **판정 근거표:** 다음 표를 두 AI가 각자 채운다.

| 항목 | 우리 쪽 | 상대 쪽 | 유리한 쪽 |
| --- | --- | --- | --- |
| 장소와의 관계 |  |  |  |
| 날과 물때 |  |  |  |
| 준비와 조력자 |  |  |  |
| 이번 대국에서 생긴 손상·부상·의심 |  |  |  |
| 건 것과 문구 |  |  |  |

3. **결과:** 두 표의 "유리한 쪽"이 대체로 같으면 그대로 결과를 정한다. 엇갈리면 사용자가 정한다.
4. **장면:** 결과가 정해진 뒤, 그 차례를 가진 AI가 맞섬 장면을 소설로 쓴다. 장면은 결과를 바꾸지 않는다.

## 차례의 길이와 판의 길이

- **한 차례 = 한 세력의 한 물때.** 행동은 두세 가지까지. 예: 회맹 협상 한 번, 사람 하나 보내기, 맞섬 준비 하나.
- **한 물때 = 두 세력의 차례 한 번씩.** 시나리오에는 두 태양이 가까워지는 철까지 세 물때가 있다. 그 사이에 맞섬 세 번이 끼어든다.
- 전체는 대략 여섯에서 여덟 차례와 마지막 장면 하나다. 너무 길어지지 않게 끝이 정해진 판이다.

## 기록 방식

- 대국 기록은 한 문서(예: `wiki/rival-great-crossing-log.md`)에 차례마다 절을 하나씩 더한다. 절 제목은 `T01 · Claude · 첫째 물때`처럼 쓴다.
- 각 절의 구성: **이의 제기(있으면) → 판정 → 새로 알게 된 것 → 행동 → 짧은 장면(선택)**.
- 차례 하나는 커밋 하나다. 자기 차례가 아닐 때는 기록 문서를 고치지 않는다. 저장소의 `PLAY.md`에 있는 수신함 묶음으로 올려도 된다.
- 세력의 현재 상태(사람, 관계, 손상, 쥔 약속)는 기록 문서 맨 위의 표에 두고 매 차례 갱신한다.

## 승패

승패는 점수가 아니라 **목표를 얼마나 이뤘는가**로 본다. 시작 때 각 세력은 목표 셋을 적는다. 하나는 공개, 둘은 기록 문서의 진행자용 절에 적는다(두 AI 모두 읽을 수 있지만 인물은 모른다). 마지막 장면 뒤에 각 목표를 이룸, 일부 이룸, 못 이룸으로 판정한다. 두 AI가 합의하지 못하는 목표는 사용자가 판정한다.

이 시나리오는 진행자용 진상상 누구도 깨끗하게 이기기 어렵게 짜여 있다. 그것이 대국의 재미가 되어야지, 어느 한쪽이 진상을 아는 덕분에 이기는 판이 되어서는 안 된다.
